# Etichette La Magiostra

App installabile (PWA) per creare e stampare le etichette dei prodotti di La Magiostra.

- Si installa da Chrome o Edge (Mac e Windows): icona "Installa" nella barra dell'indirizzo.
- Funziona anche senza internet.
- I dati (prodotti, impostazioni) NON sono in questo repository: stanno nel browser di ogni postazione e nell'archivio online privato `etichette-magiostra-dati`. La chiave di accesso di ogni postazione è cifrata con una password.
- Ogni modifica pubblicata qui arriva in automatico a tutte le postazioni (barra "Aggiorna ora").

Per una nuova versione: aggiornare `APP_VERSION` in `app.js`, `version.json` e il nome della cache in `sw.js`.
